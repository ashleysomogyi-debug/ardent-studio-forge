# Architecture Rules

- Use semantic light-theme tokens for all site-wide colors so shared components remain consistent and accessible.
- Keep the `/wow` offer page visually and behaviorally isolated from the site-wide rebrand.
- Use the shared Radix tabs component for categorized content because it provides consistent keyboard and screen-reader behavior.
- Scope the Automation and Apps cyan experiment beneath one page-level theme class so shared site styling remains unchanged and rollback stays simple.
